# Проверка сборки и установка Orbit

В проект добавлена проверка настоящей сборки приложения на macOS. Она нужна отдельно от компиляции моделей Foundation и синтаксического разбора Swift-файлов в Linux: эти проверки не проверяют доступность API SwiftUI, UIKit и SceneKit или сборку ресурсов iPhone-приложения.

## Проверка на своём Mac

Нужны Xcode 16 или новее, выбранный Xcode в настройках Command Line Tools и Python 3.10 или новее. Откройте терминал в каталоге проекта и выполните:

```sh
python3 -m unittest discover -s bridge -v
sh scripts/check-macos.sh
```

Скрипт запускает `swift test`, затем собирает target **Orbit** для iPhone Simulator с `CODE_SIGNING_ALLOWED=NO`. Для этой проверки не нужны сертификат подписи и аккаунт Apple Developer. Готовый продукт находится в `build/Build/Products/Debug-iphonesimulator/Orbit.app`.

Чтобы проверить интерфейс, откройте `AgentOrbit.xcodeproj`, выберите схему **Orbit**, выберите симулятор iPhone с iOS 17 или новее и нажмите **Run**. Сборка для generic simulator проверяет компиляцию; сама по себе она не запускает интерфейс и не проверяет нажатия.

## Автоматическая проверка GitHub

Файл [.github/workflows/ios-check.yml](../.github/workflows/ios-check.yml) запускает проверку на `macos-15` после отправки изменений в `main`, для pull request и по кнопке **Run workflow**. Репозиторий проекта — [kasock0002/IphoneApp2](https://github.com/kasock0002/IphoneApp2). Текущий результат и журналы доступны в [GitHub Actions](https://github.com/kasock0002/IphoneApp2/actions/workflows/ios-check.yml).

Workflow проверяет Python-код сервиса, Swift-ядро и сборку приложения для симулятора. Он использует стандартный Xcode выбранного runner, выводит версию в журнал и не требует секретов. Права токена ограничены чтением исходников; публикация в App Store Connect и TestFlight не выполняется.

После успешной сборки появляется artifact **Orbit-simulator-unsigned**. Это ZIP с `Orbit.app` **для симулятора**. Его нельзя установить на физический iPhone или загрузить в TestFlight как готовую iOS-сборку. Artifact хранится семь дней.

## Установка на физический iPhone

1. Откройте `AgentOrbit.xcodeproj` на Mac.
2. Выберите target **Orbit → Signing & Capabilities** и свою Team. При необходимости замените Bundle Identifier на уникальный.
3. Подключите iPhone с iOS 17 или новее, подтвердите доверие компьютеру и включите режим разработчика, если Xcode попросит.
4. Выберите подключённый iPhone как устройство и нажмите **Run**.

Подпись через личную Team может иметь ограничения Apple по сроку и распространению. Для TestFlight требуется членство Apple Developer Program, запись приложения в App Store Connect и сборка, подписанная для распространения. Эти настройки не создаются автоматически текущим workflow.

## Что проверить на устройстве

- Все проекты открываются нажатием в 3D-сцене и в обычном списке; карточка закрывается.
- Отчёты раскрываются, этап и следующие шаги читаются, отсутствующие сведения явно обозначены.
- Дата и автор сводки агентов показаны отдельно от времени обновления облачных задач.
- Уменьшение движения останавливает анимацию; уход приложения в фон не оставляет активную анимацию сцены.
- Корректный JSON импортируется и сохраняется после перезапуска; ошибочный файл сохраняет предыдущие данные.
- HTTPS-подключение получает снимок, ручное обновление работает, ошибка связи оставляет последнюю успешную сводку с сообщением об ошибке.
- Переключение на файл или деморежим приостанавливает опрос; явное отключение сервиса удаляет сохранённый токен.
- Импорт файла подключения заполняет форму; до нажатия кнопки подключения адрес и ключ не отправляются по сети.
- Кнопка импорта подключения отклоняет профиль с неизвестной версией, лишними полями, HTTP-адресом или недопустимым ключом, сохраняя предыдущие поля.

Сначала можно использовать комплектные вымышленные примеры. Для проверки реального Codex нужен сервис с действующей авторизацией CLI; пароль ChatGPT в приложение вводить не нужно.
