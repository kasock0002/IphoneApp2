# От исходников до подключения iPhone

## 1. Установить приложение

На Mac с Xcode 16 или новее откройте `AgentOrbit.xcodeproj`, выберите Team в **Signing & Capabilities**, подключите iPhone с iOS 17 или новее и нажмите **Run**. Сначала можно запустить iPhone Simulator. Подробности: [BUILD.md](BUILD.md).

В исходниках нет подписанного установочного файла. Для физического iPhone требуется подпись Apple; для TestFlight — настроенный аккаунт разработчика. Сборка для симулятора проверяется в [GitHub Actions](https://github.com/kasock0002/IphoneApp2/actions/workflows/ios-check.yml).

## 2. Запустить локальный сервис

На компьютере с Python 3.10+ установите официальный Codex CLI и выполните вход через `codex login`. Из каталога проекта:

```sh
python3 bridge/orbit_service.py run
```

При первом запуске команда получает список проектов и создаёт приватные настройки в `.orbit/service`. При следующих запусках используются те же ключи. Это локальный сервис; компьютер должен оставаться включённым, а команда — работающей. Доступ к облачному аккаунту в этой среде не настроен за вас.

Для проверки в другом терминале:

```sh
python3 bridge/orbit_service.py status
```

## 3. Подготовить HTTPS

Для доступа iPhone нужен HTTPS-адрес с доверенным сертификатом, который проксирует запросы к `127.0.0.1:8765`. Пример Caddy и требования: [../bridge/README.md](../bridge/README.md). Домен, DNS и сертификат нужно настроить на вашем хосте; локальный HTTP-адрес приложение не принимает.

## 4. Импортировать подключение на iPhone

Замените пример настоящим адресом своего сервиса:

```sh
python3 bridge/orbit_service.py connection --endpoint https://your-domain.example/snapshot --output .orbit/orbit-connection.json
```

Передайте созданный файл на свой iPhone через AirDrop или «Файлы». В Orbit откройте **Источник данных → Импортировать подключение**, выберите файл, проверьте адрес и нажмите **Подключить и обновить**.

Файл содержит ключ чтения. Передавайте его только на свои устройства и удалите ненужные копии после импорта. Сам импорт лишь заполняет форму; запросы начинаются после подтверждения.

## 5. Подключить отчёты агентов

Сервис уже подготовит отдельные токены записи для проектов первоначального снимка. Настройте секрет `ORBIT_PROJECT_WRITE_TOKEN` в окружении конкретного агента и попросите его формировать и отправлять сводку по [../bridge/PUBLISHING.md](../bridge/PUBLISHING.md). Пароль ChatGPT агенту или приложению передавать не нужно.

Для нового проекта предусмотрена команда `add-project`; порядок настройки, сохранение ключей и права файлов описаны в [SERVICE.md](SERVICE.md).

Без настроенного сервиса можно изучить приложение на комплектных вымышленных примерах. Они явно обозначены как демоданные.
